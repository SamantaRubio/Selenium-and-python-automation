# US-006 - Remove Product From Cart

## User Story
As a customer,
I want to remove products from the cart,
So that I can modify my purchase.

## Preconditions
- Product exists in cart.

## Acceptance Criteria

Given a product is already in the cart

When the user clicks "Remove"

Then the product should disappear from the cart

And the cart badge should update accordingly.

## Expected Result

Product is removed successfully.
