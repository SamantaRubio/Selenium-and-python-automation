# US-008 - Complete Checkout

## User Story
As a customer,
I want to complete a purchase,
So that I can buy my selected products.

## Preconditions
- User has at least one item in the cart.

## Acceptance Criteria

Given the user is on the cart page

When the user clicks Checkout

And enters:

- First Name
- Last Name
- Postal Code

And clicks Continue

And clicks Finish

Then the confirmation message

"Thank you for your order!"

should be displayed.

## Expected Result

Order is completed successfully.
