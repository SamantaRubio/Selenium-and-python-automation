# US-005 - Add Product To Cart

## User Story
As a customer,
I want to add products to the shopping cart,
So that I can purchase them later.

## Preconditions
- User is logged in.

## Acceptance Criteria

Given the user is on the inventory page

When the user clicks "Add to cart" for a product

Then the cart badge should increase by 1

And the button should change to "Remove"

## Expected Result

The selected product is added successfully.
