# US-003 - View Products

## User Story

As a customer,
I want to view the products list,
So that I can browse available items.

## Priority

High

## Preconditions

* User is logged in.

## Acceptance Criteria

Given the user is on the inventory page

Then the products list should be displayed

And each product should contain:

* Image
* Name
* Description
* Price
* Add to Cart button

## Expected Result

Products are displayed correctly.
